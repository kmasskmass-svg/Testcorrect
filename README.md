# المصحح الآلي OMR

تطبيق ويب يعمل في المتصفح فقط (HTML + CSS + JavaScript + OpenCV.js) لتصحيح أوراق الاختيار من متعدد بالكاميرا.

## الملفات
| الملف | الوظيفة |
|---|---|
| `index.html` | الواجهة (RTL)، الكاميرا، أزرار الالتقاط والرفع، عرض النتيجة |
| `style.css` | التنسيق |
| `app.js` | خوارزميات المعالجة والتصحيح + نماذج الإجابات (`EXAMS`) |
| `opencv.js` | نسخة احتياطية من المكتبة تُستخدم إن تعذّر تحميلها من الإنترنت |
| `sheet.html` | ورقة إجابة A4 مطابقة للتطبيق (10 أسئلة × 4 خيارات) جاهزة للطباعة |

## النشر على GitHub Pages
1. أنشئ مستودعاً جديداً وارفع الملفات الأربعة في جذره.
2. Settings ← Pages ← Source: `Deploy from a branch` ← الفرع `main` / المجلد `/ (root)`.
3. افتح الرابط `https://<اسمك>.github.io/<المستودع>/` من الجوال (HTTPS ضروري لتشغيل الكاميرا).

## تعديل نموذج الإجابة
في أعلى `app.js` داخل `EXAMS`: الأرقام تبدأ من 0 (0=أ، 1=ب، 2=ج، 3=د).
عند تغيير عدد الأسئلة أو الخيارات عدّل `CONFIG` في `app.js` و `NUM_QUESTIONS`/`LABELS` في `sheet.html` معاً.

## نصائح للتصوير
- اطبع الورقة من `sheet.html` ولا تكتب شيئاً داخل الإطار الأسود.
- ضع الورقة على سطح داكن، وصوّرها كاملة بإضاءة متساوية دون ظلال.
- إن فشل التصحيح افتح «مراحل المعالجة» لرؤية صورة الحواف والعتبة.
